Modelos Autoregresivos \(AR(p)\)

Un proceso \(\{X_t\}\) es autoregresivo de orden \(p\) si satisface la ecuación:

\[ X_t = \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + Z_t, \qquad Z_t \sim \mathrm{WN}(0,\sigma^2) \]

Podemos resumir un modelo \(AR(p)\) en términos del polinomio de retraso:

\[ \Phi(B)\, X_t = Z_t \]

Donde \(B\) es el operador de retraso está definido por \(B^k X_t = X_{t-k}\), y entonces el polinomio de retraso es

\[ \Phi(B) = 1 - \phi_1 B - \phi_2 B^2 - \cdots - \phi_p B^p \]

El proceso es estacionario de segundo orden si todas las raíces de \(\Phi(B)\) caen fuera del círculo unitario, es decir \(|z_i| > 1\) para toda \(z\) que cumpla \(\Phi(z)=0\) . En ese caso existe la representación \(MA(\infty)\)

\[ X_t = \Phi^{-1}(B) Z_t = \sum_{j=0}^{\infty} \psi_j Z_{t-j} \qquad \text{donde} \quad \sum_{j=0}^{\infty}|\psi_j| < \infty \]

Para un modelo \(AR(1)\), el polinomio de retraso es \(\Phi(B) = 1-\phi B\) y la única raíz es \(z = 1/\phi\), entonces la condición para que sea estacionario de segundo orden es que \(|z|>1\), y es equivalente a que \(|\phi|<1\). Si se cumple lo anterior, entonces:

\[ \mathbb{E}[X_t]=0, \qquad \gamma(0)=\mathrm{Var}(X_t)=\frac{\sigma^2}{1-\phi^2} \]

ACF y PACF

Expresión para AR(p)

Multiplicando \(X_t = \Phi^{-1}(B) Z_t\) por \(X_{t-h}\) y tomando esperanzas se obtienen las ecuaciones Yule–Walker:

\[ \gamma(h) = \phi_1\gamma(h-1) + \cdots + \phi_p\gamma(h-p), \qquad h \ge 1, \]

Dividiendo entre \(\gamma(0)\),

\[ \rho(h) = \phi_1\rho(h-1) + \cdots + \phi_p\rho(h-p), \qquad h \ge 1 . \]

Es una ecuación en diferencias (lineal) cuya solución general es

De modo que la ACF decae (exponencialmente, o con oscilación si hay términos negativos o raíces complejas) pero no se corta en cierto punto.

Sin entrar en detalles técnicos, la PACF \(\alpha(h)\) para un modelo \(AR(p)\) es:

\[ \alpha(h) \ne 0 \ \text{ para } h \le p, \qquad \alpha(h) = 0 \ \text{ para } h > p \]

Ese corte en el rezago \(p\) nos ayudará a “identificar” el orden del modelo para unos datos observados.

Expresión para AR(1) estacionario

Como \(\rho(h)=\phi\rho(h-1)\) y \(\rho(0)=1\):

En este caso, la ACF es:

\[ \rho(h) = \phi^{|h|}, \qquad h = 0,\pm 1,\pm 2,\dots \]

Si \(0<\phi<1\) la ACF decae monótonamente; si \(-1<\phi<0\) decae alternando signo.

Mientras que la PACF queda determinada por: \[ \alpha(1) = \phi, \qquad \alpha(h) = 0 \quad \text{para } h>1 . \]

Podemos obtener las funciones de autocorrelación teóricas para un modelo completamente especificado, con la función ARMAacf(). A continuación se muestra un ejemplo para el modelo \(AR(1)\) con \(\phi = 0.8\) y \(\phi = - 0.8\), se puede ver que en el segundo caso la ACF oscila y en la PACF el único valor es para el rezago \(1\) pero con signo negativo.

Raíces del polinomio

Para saber si el modelo \(AR(p)\) es estacionario de segundo orden, analizamos las raíces del polinomio de retraso

\[ \Phi(B) = 1 - \phi_1 B - \phi_2 B^2 - \cdots - \phi_p B^p \]

La función polyroot() recibe los coeficientes \((1,- \phi_1, ..., - \phi_p)\) y devuelve las raíces del polinomio. Otra forma es visualizar las raices, en esta gráfica queremos que los puntos estén fuera del círculo unitario. Para ilustrar estos métodos, supongamos un modelo \(AR(1)\) con \(\phi = 0.8\)

Code 
phi <- c(0.8)                  # AR(1)
coef_ar <- c(1, -phi)                # 1 - 0.8z 
raices_ar <- polyroot(coef_ar)

# funcion manual
plot_raices <- function(raices, titulo = "Raíces y círculo unitario") {
  theta <- seq(0, 2*pi, length.out = 400)
  lim <- max(1.5, max(Mod(raices)) * 1.2)
  plot(cos(theta), sin(theta), type = "l", lwd = 2, col = "grey40",
       asp = 1, xlim = c(-lim, lim), ylim = c(-lim, lim),
       xlab = "Re(z)", ylab = "Im(z)", main = titulo)
  abline(h = 0, v = 0, lty = 3, col = "grey70")
  points(Re(raices), Im(raices), pch = 19, cex = 1.4,
         col = ifelse(Mod(raices) > 1, "forestgreen", "firebrick"))
  text(Re(raices), Im(raices), labels = round(Mod(raices), 2), pos = 3, cex = .8)
  legend("topleft", bty = "n", pch = 19, cex = .8,
         col = c("forestgreen", "firebrick"),
         legend = c("|z| > 1", "|z| <= 1"))
}

plot_raices(raices_ar, "Raices de AR(1) con phi=0.8")

Simulación

Podemos simular un modelo \(AR(1)\) con \(X_0 = 0\) y \(Z_t \sim GWN(0,1)\) con distintos valores del parámetro de persistencia \(\phi\) para ilustrar lo que pasa cuando está dentro del circulo unitario o fuera de él.

Code 
sim_ar1 <- function(n, phi, x0 = 0, sd = 1) {   
  z <- rnorm(n, sd = sd)
  x <- numeric(n)
  x[1] <- phi * x0 + z[1]
  for (t in 2:n) x[t] <- phi * x[t-1] + z[t]
  ts(x)
}

n <- 300
x_est  <- sim_ar1(n, phi = 0.7)   # |phi| < 1  -> estacionario
x_unit <- sim_ar1(n, phi = 1.0)   # |phi| = 1  -> caminata aleatoria
x_exp  <- sim_ar1(n, phi = 1.05)  # |phi| > 1  -> explosivo

par(mfrow = c(3, 1), mar = c(4, 4, 3, 1))
plot(x_est,  ylab = expression(X[t]), col = "steelblue",
     main = expression(paste("AR(1) con ", phi == 0.7, ": Estacionario")))
abline(h = 0, lty = 2)
plot(x_unit, ylab = expression(X[t]), col = "darkorange",
     main = expression(paste("AR(1) con ", phi == 1, ": Raíz unitaria (Caminata aleatoria Gaussiana)")))
abline(h = 0, lty = 2)
plot(x_exp,  ylab = expression(X[t]), col = "firebrick",
     main = expression(paste("AR(1) con ", phi == 1.05, ": Explosivo")))

Modelos de Medias Móviles \(MA(q)\)

Un proceso \(\{X_t\}\) es de medias móviles de orden \(q\) si satisface la ecuación:

\[ X_t = Z_t + \theta_1 Z_{t-1} + \cdots + \theta_q Z_{t-q}, \qquad Z_t \sim \mathrm{WN}(0,\sigma^2). \]

En términos del polinomio de retraso:

\[ X_t = \Theta(B)\, Z_t, \qquad \Theta(B) = 1 + \theta_1 B + \cdots + \theta_q B^q . \]

Un \(MA(q)\) siempre es estacionario de segundo orden, además

\[ \mathbb{E}[X_t]=0, \qquad \gamma(0) = \sigma^2\sum_{j=0}^{q}\theta_j^2, \quad \theta_0 = 1 . \]

Para este modelo, la propiedad no trivial es la invertibilidad: que las raíces de \(\Theta(B)\) caigan fuera del círculo unitario, es decir \(|z_i|>1\). Eso permite escribir la representación \(AR(\infty)\)

\[ \Theta^{-1}(B) X_t = Z_t \]

Para un modelo \(MA(1)\) dado por \(\Theta(B)=1+\theta B\), la raíz es \(z=-1/\theta\) y la invertibilidad equivale a \(|\theta|<1\).

ACF y PACF

Expresión para MA(q)

\[ \gamma(h) = \begin{cases} \sigma^2 \displaystyle\sum_{j=0}^{q-|h|} \theta_j \theta_{j+|h|}, & |h| \le q,\\[2mm] 0, & |h| > q, \end{cases} \qquad \theta_0 = 1, \]

de donde

\[ \rho(h) = \frac{\sum_{j=0}^{q-|h|}\theta_j\theta_{j+|h|}}{\sum_{j=0}^{q}\theta_j^2} \ \ (|h|\le q) \qquad \rho(h) = 0 \ \text{ para } |h| > q \]

La ACF se corta en el rezago \(q\), mientras que la PACF decae sin cortarse. Es exactamente el comportamiento contrario al del \(AR(p)\).

Expresión para MA(1)

\[ \rho(1) = \frac{\theta}{1+\theta^2} \qquad \rho(h) = 0 \ \ \text{para } h \ge 2 \]

Sabemos que \(|\rho(1)|\le 1/2\) siempre, y que \(\theta\) y \(1/\theta\) producen la misma ACF (problema de identificación que resuelve la invertibilidad: se elige la raíz con \(|\theta|<1\)).

La PACF del \(MA(1)\) invertible es

\[ \alpha(h) = -\frac{(-\theta)^h\,(1-\theta^2)}{1-\theta^{2(h+1)}}, \qquad h\ge 1, \]

que decae geométricamente y alterna de signo cuando \(\theta>0\).

Simulación

Simulamos un \(MA(1)\): \(X_t = Z_t + \theta Z_{t-1}\) con tres valores de \(\theta\). Usamos filter() para poder incluir \(|\theta|\ge 1\) (todos son estacionarios, pero sólo el primero es invertible).

Code 
sim_ma1 <- function(n, theta, sd = 1) {
  z <- rnorm(n + 1, sd = sd)
  ts(stats::filter(z, filter = c(1, theta), method = "convolution", sides = 1)[-1])
}

m_inv   <- sim_ma1(n, theta = 0.8)   # |theta| < 1 -> invertible
m_unit  <- sim_ma1(n, theta = 1.0)   # |theta| = 1 -> frontera, no invertible

A diferencia del \(AR(1)\), ninguna de las tres trayectorias explota, pues el \(MA(1)\) es estacionario para cualquier \(\theta\). Lo que cambia es la invertibilidad, y con ella la posibilidad de recuperar \(Z_t\) a partir del pasado observado de \(X_t\). Además \(\theta=0.8\) y \(\theta=1/0.8=1.25\) generan las mismas ACF, por lo que sólo la versión invertible es identificable en la estimación.

Modelos \(ARMA(p,q)\)

Un proceso \(\{X_t\}\) es \(ARMA(p,q)\) si satisface la siguiente ecuación:

\[ X_t - \phi_1 X_{t-1} - \cdots - \phi_p X_{t-p} = Z_t + \theta_1 Z_{t-1} + \cdots + \theta_q Z_{t-q}, \]

o de forma compacta con los polinomios de retraso:

\[ \Phi(B)\,X_t = \Theta(B)\,Z_t \]

con \(\Phi(B)=1-\phi_1B-\cdots-\phi_pB^p\) y \(\Theta(B)=1+\theta_1B+\cdots+\theta_qB^q\).

Las propiedades de interés son:

  • Causalidad / estacionariedad: raíces de \(\Phi(B)\) fuera del círculo unitario.
  • Invertibilidad: raíces de \(\Theta(B)\) fuera del círculo unitario.
  • Identificabilidad: \(\Phi(B)\) y \(\Theta(B)\) no deben tener raíces comunes, y si las tienen el modelo se reduce a uno de orden menor.

Bajo causalidad, \[ X_t = \Psi(B)Z_t \qquad \text{con} \qquad \Psi(B)=\Theta(B)/\Phi(B)=\sum_{j=0}^{\infty}\psi_j B^j \]

Los coeficientes anteriores se obtienen en R con ARMAtoMA().

Code 
ARMAtoMA(ar = 0.7, ma = 0.4, lag.max = 8)   # pesos psi_j de la representación MA(infinito)
[1] 1.10000000 0.77000000 0.53900000 0.37730000 0.26411000 0.18487700 0.12941390
[8] 0.09058973

ACF y PACF

Las funciones de autocorrelación serán heredadas de cada componente, es decir, la ACF será heredada del componente \(MA(q)\) y la PACF será heredada del \(AR(q)\), esto nos ayudará a identificar los parámetros del modelo posteriormente.

Expresión para ARMA(p,q)

Una tabla que ayuda a la identificación:

Modelo ACF PACF
\(AR(p)\) decae se corta en \(p\)
\(MA(q)\) se corta en \(q\) decae
\(ARMA(p,q)\) decae (tras \(q\)) decae (tras \(p\))

Ninguna de las dos funciones se corta, por lo que en la práctica el orden se elige con criterios de información (AIC/BIC). En R la función que ayuda a estimar los parámetros del modelo es forecast::auto.arima().

arima.sim()

La función que nos ayuda a simular observaciones de un proceso completamente especficiado es arima.sim. Una limitante es que solo permite simular procesos estacionarios.

Expresión para ARMA(1,1)

Con \(X_t = \phi X_{t-1} + Z_t + \theta Z_{t-1}\) y \(|\phi|<1\):

\[ \gamma(0) = \sigma^2\,\frac{1+2\phi\theta+\theta^2}{1-\phi^2}, \]

\[ \rho(1) = \frac{(1+\phi\theta)(\phi+\theta)}{1+2\phi\theta+\theta^2}, \qquad \rho(h) = \phi\,\rho(h-1) \ \ \text{para } h \ge 2 . \]

Es decir, la ACF decae geométricamente a tasa \(\phi\) a partir del rezago 1, pero con un “arranque” distinto al del \(AR(1)\) puro. Si \(\theta=0\) se recupera \(\rho(h)=\phi^h\); si \(\phi=0\) se recupera la ACF del \(MA(1)\).

Simulacion

Simulamos \(ARMA(1,1)\): \(X_t = \phi X_{t-1} + Z_t + \theta Z_{t-1}\), con una recursión propia que admite valores fuera de la región causal/invertible.

Code 
sim_arma11 <- function(n, phi, theta, sd = 1) {
  z <- rnorm(n, sd = sd)
  x <- numeric(n)
  x[1] <- z[1]
  for (t in 2:n) x[t] <- phi * x[t-1] + z[t] + theta * z[t-1]
  ts(x)
}

a_ok    <- sim_arma11(n, phi = 0.7,  theta = 0.4)   # causal e invertible
a_unit  <- sim_arma11(n, phi = 1.0,  theta = 0.4)   # raiz unitaria en Phi -> ARIMA(0,1,1)
a_exp   <- sim_arma11(n, phi = 1.05, theta = 0.4)   # explosivo

par(mfrow = c(3, 1), mar = c(4, 4, 3, 1))
plot(a_ok,   ylab = expression(X[t]), col = "steelblue",
     main = expression(paste("ARMA(1,1): ", phi == 0.7, ", ", theta == 0.4, " (causal e invertible)")))
abline(h = 0, lty = 2)
plot(a_unit, ylab = expression(X[t]), col = "darkorange",
     main = expression(paste("ARMA(1,1): ", phi == 1, ", ", theta == 0.4, " (raíz unitaria)")))
abline(h = 0, lty = 2)
plot(a_exp,  ylab = expression(X[t]), col = "firebrick",
     main = expression(paste("ARMA(1,1): ", phi == 1.05, ", ", theta == 0.4, " (explosivo)")))
abline(h = 0, lty = 2)

Resumen

\(AR(p)\) \(MA(q)\) \(ARMA(p,q)\)
Notación \(\Phi(B)X_t=Z_t\) \(X_t=\Theta(B)Z_t\) \(\Phi(B)X_t=\Theta(B)Z_t\)
Estacionariedad Raíces de \(\Phi\) fuera Siempre Raíces de \(\Phi\) fuera
Invertibilidad Siempre Raíces de \(\Theta\) fuera Raíces de \(\Theta\) fuera
ACF Decae Se corta en \(q\) Decae
PACF Se corta en \(p\) Decae Decae
Representación alternativa \(MA(\infty)\) \(AR(\infty)\) Ambas
