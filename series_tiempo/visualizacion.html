La paqueteria dygraphs


library(dygraphs)
lungDeaths <- cbind(ldeaths, mdeaths, fdeaths)

dygraph(lungDeaths,main="Muertes por cancer de pulmon 1974 - 1979") %>%
  dySeries("mdeaths", label = "Hombre") %>%
  dySeries("fdeaths", label = "Mujer") %>%
  dyOptions(stackedGraph = TRUE) %>%
  dyRangeSelector(height = 20)

Ejemplo con dygraphs

Tambien se pueden personalizar otras cosas como:



dygraph(lungDeaths, main = "Deaths from Lung Disease (UK)", width = "100%", height = "400px") %>%
  dyHighlight(highlightSeriesOpts = list(strokeWidth = 3))

Otra alternativa

dygraph(lungDeaths, main = "Deaths from Lung Disease (UK)",width = "100%") %>%
  dyHighlight(highlightSeriesOpts = list(strokeWidth = 5),
              highlightCircleSize = 5)
